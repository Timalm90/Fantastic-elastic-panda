</p>

## Features

- **Interactive Facial Controls**: Manipulate panda facial expressions using drag gestures and blendshape-based controls
- **Timed Gameplay**: Recreate target expressions before the countdown expires
- **Expression Scoring**: Earn scores based on how accurately you match the target expression
- **Leaderboard**: Track performance and compete for high scores
- **Backend Validation**: Supabase integration for score validation and anti-cheat protection
- **Mobile-First Design**: Responsive interface designed for both mobile and desktop devices

## Technologies Used

- **React**: Component-based UI development
- **TypeScript**: Type-safe application development
- **Three.js**: 3D rendering and interactive facial models
- **Supabase**: Backend services, score validation and leaderboard functionality
